## 원문의 핵심

일반적인 검색 기반 답변은 질문할 때마다 자료를 다시 조합합니다. 이 제안은 원본과 답변 사이에 지속적으로 유지하는 위키를 둡니다. 새 출처가 들어오면 요약·개념·상호 참조·상충 내용을 갱신하여 다음 질의에 재사용합니다.

원본, 생성 위키, 구조·작업을 정하는 스키마를 분리합니다. `index.md`는 내용별 탐색을, `log.md`는 시간순 이력을 담당합니다. 수집·질의·점검을 반복하고 가치 있는 질의 결과도 위키에 보관합니다.

## 이번 적용

| 원문의 패턴 | 이 폴더의 적용 |
| --- | --- |
| 원본 보존 | `raw/`에 PDF·Gist를 그대로 보관하고 해시 기록 |
| 지식을 미리 정리 | 법률별 안내와 공통 개념 문서 작성 |
| 원본과 합성 분리 | `derived/` 추출 텍스트, `wiki/` 분석 문서 구분 |
| 추적 가능한 연결 | 법률별 PDF 페이지와 관련 개념 연결 |
| 상충 내용 유지 | 파일 기준일과 제작일 차이, 현행성 한계를 검토 문서에 기록 |
| 탐색과 이력 | `wiki/index.md`, `wiki/log.md` |
| 일관된 유지관리 | `wiki/schema.md`에 인용·수집·질의·점검 규칙 명시 |

## 채택하지 않은 항목과 한계

검색 엔진·벡터 DB·외부 LLM API·Obsidian 플러그인을 설치하지 않았습니다. 원문의 선택적 도구 제안은 실행 지시로 취급하지 않았습니다. 원문의 유지 비용·효과에 대한 일반 주장은 이 작업에서 실험으로 검증하지 않았습니다.

세법 자료에서는 자동 합성의 편의보다 적용 시점과 조문의 정확성이 우선입니다. 위키 요약은 법령의 효력을 판정하거나 원문을 대체하지 않습니다. [검토 사항](../review.md)을 함께 봅니다.
