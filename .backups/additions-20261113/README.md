## 폴더

- `raw/`: 수집한 원본과 출처 메타데이터. 기존 원본은 변경하지 않습니다.
- `derived/`: PDF에서 추출한 텍스트와 문서 구조. 원본을 대체하지 않습니다.
- `wiki/`: 출처 요약, 법률별 안내, 개념 연결, 검토 사항.

## 주의

원본 파일명은 2011년 5월 기준이지만 PDF 표지와 제작 메타데이터에는 2013년 11월 11일이 표시됩니다. 법률별 시행일과 개정 표기를 구분하여 읽어야 합니다. 현재 적용 여부는 이 자료만으로 판단하지 않습니다.
