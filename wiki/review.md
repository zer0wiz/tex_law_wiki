# 검토 사항과 적용 제한

[색인](index.md) · [PDF 분석](sources/tax-law-2011.md)

R-01~R-06은 기존 법령집의 확인 결과입니다. 이번 추가 집행기준·신고안내의 확인 사항은 R-07부터 기록합니다.

## R-01: 파일명과 본문 날짜 불일치 — 확인됨

파일명과 표지 제목은 2011년 5월 기준입니다. 표지 날짜·PDF 메타데이터는 2013.11.11입니다. PDF 3쪽의 국세기본법은 법률 제11845호·2013.5.28, 224쪽의 법인세법 시행령은 2013.11.5로 표시됩니다. 따라서 이 파일을 2011년 5월 시점의 일관된 법령집으로 취급하지 않습니다.

## R-02: 수록 법령의 시점 혼재 — 확인됨

지방세기본법은 PDF 3411쪽에 시행 2011.10.13, 시행령은 3464쪽에 시행 2011.1.1, 시행규칙은 3496쪽에 시행 2011.1.1로 표시됩니다. 이 세 항목도 모든 시점에서 동시에 유효했다고 단정할 수 없습니다. 법률과 하위 규정의 기준일을 각각 확인합니다.

## R-03: 현행법 적용 — 미검증

현행 공식 법령, 개정 연혁, 판례·예규를 조회하지 않았습니다. 특정 거래·상속·신고의 세율·공제·기한이나 납세의무를 이 위키만으로 확정하지 않습니다. 실제 사안에서는 과세시점의 공식 법령과 부칙을 대조합니다.

## R-04: 자동 추출과 3단 비교 — 구조적 한계

모든 페이지에 추출 텍스트는 있습니다. 그러나 열 구분·표·수식·서식의 정확성은 전수 검증하지 않았습니다. 예를 들어 PDF 298쪽에는 법인세법 제14조와 시행령 제97조가 함께 나타납니다. 추출 순서가 법률의 조문 순서나 같은 번호 조문의 대응을 뜻하지 않습니다.

## R-05: 페이지 번호 — 확인됨

물리적 PDF 224쪽의 인쇄 표기는 225, 1291쪽은 1293, 3643쪽은 3789입니다. 오프셋은 일정하지 않습니다. 이 위키의 모든 페이지 인용은 PDF 뷰어 순번입니다.

## R-06: 분석의 깊이 — 명시된 한계

전체 3,978쪽은 기계적으로 추출했습니다. 법률별 구조와 선별 핵심 조문을 해석하여 연결했습니다. 모든 조문·별표·서식을 읽고 검증했다는 뜻이 아닙니다. 미검토 조문은 일반 지식만으로 확정하지 않습니다.

## 새 자료를 받을 때

같은 제목이라도 해시·개정번호·시행일을 비교합니다. 현행 법령이나 2011년 확정본을 받으면 별도 원본으로 등록하고 이번 사본과 차이를 기록합니다. 지금 원본을 이름만 바꾸거나 덮어쓰지 않습니다.

## R-07: 2026 집행기준의 자료 성격·기준월 — 확인됨

추가 집행기준 10종은 각각 PDF 5쪽에서 기본통칙을 보완하는 실무지침이며 2026년 9월 기준이라고 설명합니다. 머리말은 2026년 10월입니다(각 3쪽). 법령집을 대체하는 자료나 모든 조문의 시행일을 확정하는 표로 사용하지 않습니다. [자료 유형·버전](concepts/source-authority-and-versioning.md)에 적용 규칙을 기록했습니다.

## R-08: 동일 내용 사본 — 확인됨·보존

종합부동산세·증권거래세 책자의 일반 파일과 `(1)` 파일은 SHA-256이 같습니다. 두 원본을 그대로 보존하고 추출·분석은 한 번만 수행했습니다. [원본 목록](sources/index.md)에서 두 파일을 모두 연결합니다.

## R-09: 추가 자료의 추출 공백·표지 문자 오류 — 확인됨

고유 자료 11개 1,925쪽을 추출했습니다. 텍스트가 없는 59쪽은 [축소 렌더링 모음](../derived/additions-20261113/empty-text-pages-contact-sheet.png)에서 공백으로 관찰했습니다. 원천세 안내 표지의 글꼴 매핑 오류는 [표지 이미지](../derived/additions-20261113/withholding-cover.png)로 제목과 2026년 9월 표기를 확인했습니다. 추출 원문은 덮어쓰지 않았습니다. 이 점검은 전체 표·이미지·수식 전사의 정확성 보증이 아닙니다.

## R-10: 미래 예정 사항과 대비표 — 적용 전 확인

원천세 안내 PDF 12쪽은 2027년 간이지급명세서(근로소득) 변경을 ‘예정’으로 표시합니다. 이를 확정 시행으로 쓰지 않습니다. 집행기준 말미의 ‘종전/개정안’ 표 역시 책자 내부 비교 자료이며 이 위키의 과거 법령집과 전수 비교했다는 뜻이 아닙니다.

## R-11: 새 자료의 현행 적용·진본성 — 외부 대조 미실시

사용자가 보관한 사본의 설명과 본문을 확인했습니다. 공식 배포 사이트·후속 개정·부칙·판례의 현재 상태를 대조하지 않았습니다. [추가 자료 분석](sources/additions-20261113.md)은 구조와 핵심 기준의 선별 분석이며 실제 신고·납부·세액 계산 결과가 아닙니다.
