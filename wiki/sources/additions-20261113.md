## 수집과 보존

사용자가 `raw/`에 추가한 PDF 12개를 확인했습니다. 개별 파일명과 SHA-256으로 기존 반영 자료·동일 내용 사본을 구분했습니다. 원본 파일을 수정·이동·삭제하지 않았습니다. 기존 PDF·Gist·수집 메타데이터도 그대로 보존했습니다.

고유 자료는 **11개·1,925쪽**입니다. 중복 사본을 포함한 실제 파일의 페이지 합은 1,991쪽입니다. 종합부동산세·증권거래세 책자의 일반 파일과 `(1)` 파일은 SHA-256 `f7f961a3d900fa9a3a44ca84cf88da9de9aff982a909c235de653c56e8691d7f`로 동일합니다. 대표 파일을 한 번 추출하고 별칭을 기록했습니다.

- [추가 원본 메타데이터](../../raw/manifest-20261113-additions.json): 원본 식별자·파일명·별칭·해시·관측 시각.

## 적용 시점을 구분한 통합

집행기준 10종은 각 PDF 5쪽에서 **2026년 9월 기준**의 세법 내용·기본통칙·판례·질의회신을 토대로 하는 실무지침이라고 설명합니다. 머리말은 2026년 10월입니다(각 PDF 3쪽). 원천세 신고안내는 표지·머리말이 2026년 9월입니다.

[기존 법령집](tax-law-2011.md)은 제목상 2011년이지만 2013년 주요 법령과 2011년 시행 지방세 규정이 혼재합니다. 새 집행기준은 이 과거 사본의 교정본이 아닙니다. 자료 유형·기준 시점·개별 적용일을 나누어 연결했습니다. 개정 차이의 전수 대조나 현행법 확정은 하지 않았습니다.

새로 작성한 [원천징수 체크리스트](../concepts/withholding-workflow.md)는 지급자·소득자, 소득 구분, 신고·납부·지급명세서를 나누어 읽게 합니다. [자료 권위와 버전](../concepts/source-authority-and-versioning.md)은 법령·집행기준·신고안내를 구분하는 공통 기준입니다.

## 추출 품질과 분석 수준

`pypdf 7.0.1`로 고유 자료 11개 전체 1,925쪽을 처리했습니다. 공백을 제외한 추출 텍스트가 없는 페이지는 59쪽입니다. [해당 페이지의 축소 렌더링 모음](../../derived/additions-20261113/empty-text-pages-contact-sheet.png)에서 공백 페이지로 관찰했습니다. 이는 모든 표·이미지의 완전 추출을 보증하지 않습니다.

원천세 안내의 표지는 글꼴 매핑 문제로 문자 추출이 깨집니다. [표지 렌더링](../../derived/additions-20261113/withholding-cover.png)에서 제목·발간월·국세청 표기를 확인하고, 깨진 자동 추출문도 원관측대로 보존했습니다. OCR로 원본을 수정하지 않았습니다.

분석 문서는 각 책자의 일러두기·구조와 실제 본문의 선별 핵심 기준을 읽고 작성했습니다. 모든 기준·판례·세액 계산·표·서식의 전문 검토가 아닙니다. 공식 사이트와의 진본성 확인, 후속 개정 조회, 실제 신고·납부·제출은 수행하지 않았습니다.
